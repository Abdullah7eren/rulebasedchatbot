**Rule-Based AI Chatbot**
A simple rule-based AI chatbot built with pure Python for my internship at DecodeLabs (Batch 2026).

**Project Overview**
This is a deterministic, rule-based chatbot that responds to predefined user inputs using explicit if-else logic within a continuous execution loop. Before building systems that learn on their own, it's essential to master the art of teaching a machine through explicit instructions.

**Project Goals**
- Create a simple rule-based chatbot
- Handle greetings and exit commands
- Use if-else logic for responses
- Run in a continuous loop

**Key Skills Demonstrated**
- Control flow
- Decision-making logic
- Deterministic systems
- Hash map/dictionary lookup

**Features**
| _Feature_ | _Description_ |
|---------|-------------|
|  **Greetings** | Responds to hello, hi, good morning, etc. |
|  **Farewells** | Handles bye, exit, quit commands |
|  **AI Knowledge** | Answers questions about AI, ML, deep learning |
|  **Time & Date** | Tells current time and date |
|  **Fun** | Tells jokes and responds to "thank you" |
|  **Help Menu** | Shows all available commands |
|  **Continuous Loop** | Runs until user types 'exit' |
|  **Conversation History** | Tracks all interactions |
